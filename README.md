# Universal Money Address (UMA) Golang SDK

A Go SDK for implementing the Universal Money Address (UMA) protocol. UMA is an open protocol that makes sending money as easy as sending an email, using human-readable addresses like $alice@bank.com.

See [this repository](https://github.com/lightsparkdev/go-sdk/tree/main/examples/uma-server) for a sample implementation and check out the [full documentation](https://docs.uma.me) for more info.
